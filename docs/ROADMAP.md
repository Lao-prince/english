# Roadmap

| Phase | Scope |
| --- | --- |
| 0. Foundation | Local workspace, documentation, browser shell, API liveness and initial Prisma schema. |
| 1. Identity and core UI | Define onboarding and role provisioning, implement Telegram launch verification and sessions, add initial migrations and role-based screens. |
| 2. Schedule and booking | Publish one-off slots, book and cancel with concurrency protection, run the first pilot. Extend to recurrence and rescheduling once their policies are agreed. |
| 3. Students and subscriptions | Student profiles and search, credit ledger, balances, expiry and lesson settlement. |
| 4. Bot and notifications | Bot menu setup, reminders, delivery tracking, preferences and Zoom links. Configure the Mini App entry point for the pilot in Phase 1. |
| 5. Payments | Manual records, confirmation, history and a later provider decision. |
| 6. Learning materials | Homework, summaries, file access controls and publication notifications. |
| 7. Delivery | Full workflow tests, production hardening and Docker Compose, Nginx and VPS deployment. |
