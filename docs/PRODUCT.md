# Product

English Space is a Telegram-first workspace for a single independent English teacher. The teacher publishes availability and manages lessons, students, subscriptions, payments and learning materials. Students book sessions and access their own records. The same web application opens in a regular browser, with authenticated browser access planned separately.

## Proposed first pilot

- Telegram sign-in with teacher and student roles. The teacher publishes one-off availability and views booked lessons.
- Students see available times in their local time zone, book a lesson and see upcoming bookings. Cancellation follows an agreed policy. The teacher can close unused availability.
- Booking is exclusive even when multiple students select the same slot. Private data is scoped to its owner or the teacher.
- The first dashboard prioritizes upcoming lessons and booking. Repeat availability, rescheduling, subscriptions, notifications, payments and materials follow in the roadmap.
